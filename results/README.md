# Results and testing evidence

Put final evaluation artifacts in this folder, including:

- precision, recall, mAP, and confusion-matrix outputs;
- sample annotated predictions;
- Test 1 Figure-8 line detection/tracking results;
- Test 2 specialization results;
- command logs showing the SEE -> DECIDE -> ACT sequence.

Use subfolders such as `test_1/` and `test_2/` when adding the final files.
Do not store temporary caches or virtual-environment files here.
