# Training experiments

The notebooks in this directory record the project’s dataset preparation,
training, evaluation, and robot-testing experiments:

- `test_2_robot.ipynb`
- `test_2_robot_again.ipynb`
- `test_4.ipynb`
- `test_4_improvement.ipynb`

Install the root dependencies and follow
[`../../dataset/README.md`](../../dataset/README.md) before running a notebook.
Record the final notebook, hyperparameters, dataset split, checkpoint, and
metrics in the project report. The reproducible live inference entry point is
[`../testing/testing.py`](../testing/testing.py).
